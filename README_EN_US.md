**Zarnkina Mobile** is a fully Turkish, purple-themed launcher for **Android devices** tailored for [Minecraft: Java Edition](https://www.minecraft.net/). The project uses [PojavLauncher](https://github.com/PojavLauncherTeam/PojavLauncher) as its core launching engine and features a modern UI built with **Jetpack Compose** and **Material Design 3**.

## 🎯 Features

- 🇹🇷 **Fully Turkish Interface** - Default language is Turkish
- 💜 **Purple Dark Theme** - Modern, eye-friendly theme
- 🧩 **All Mod Loaders** - Forge, Fabric, Quilt, NeoForge
- 🔑 **Microsoft + Offline Login** - Easy QR code login
- 🎨 **Skin + Cape Management** - 3D preview skin editing
- 👁️ **Account Tracking** - Name history, skin changes
- 📦 **Modpack Support** - CurseForge, Modrinth import

## 📦 APK Download

Download the latest APK from GitHub:

3. Run **Build APK** workflow
4. Download APK from **Artifacts** section

## 🔧 Development

### Requirements

- Android Studio **Bumblebee** or newer
- Android SDK:
  - **Minimum API**: 26
  - **Target API**: 35
- JDK 17

### Installation

```bash
git clone https://github.com/vasndalinfinity/ZarnkinaMobile.git
# Open project in Android Studio
```

### Build

```bash
cd ZarnkinaMobile
./gradlew :ZalithLauncher:assembleDebug
```
