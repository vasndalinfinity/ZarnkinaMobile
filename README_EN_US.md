# Zarnkina Mobile

![Downloads](https://img.shields.io/github/downloads/vasndalinfinity/ZarnkinaMobile/total)

[Türkçe](README.md)


**Zarnkina Mobile** is a Turkish-first, purple-themed Minecraft: Java Edition launcher for Android devices.

It brings account management, Java runtimes, Minecraft version installation, mod loaders, modpacks, skin and cape management, and in-game touch controls into one launcher experience. The Zarnkina star logo and dark purple theme are used throughout the application.

## 🎯 Features

- 🇹🇷 **Fully Turkish Interface** - Default language is Turkish
- 💜 **Purple Dark Theme** - Modern, eye-friendly theme
- 🧩 **All Mod Loaders** - Forge, Fabric, Quilt, NeoForge
- 🔑 **Microsoft + Offline Login** - Easy QR code login
- 🎨 **Skin + Cape Management** - 3D preview skin editing
- 👁️ **Account Tracking** - Name history, skin changes
- 📦 **Modpack Support** - CurseForge, Modrinth import

## 🔧 Development

### Requirements

- Android Studio **Bumblebee** or newer
- Android SDK:
  - **Minimum API**: 26
  - **Target API**: 35
- JDK 17

### Installation

```bash
git clone https://github.com/vasndalinfinity/ZarnkinaMobile.git
# Open project in Android Studio
```

### Build

```bash
cd ZarnkinaMobile
./gradlew :app:assembleDebug
```
